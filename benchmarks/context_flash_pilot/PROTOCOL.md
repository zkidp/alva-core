# Bounded context Flash developmental pilot

User authorized continuation and Flash use. This is at most nine fresh sessions:
three **Codex-authored small maintenance fixtures**, not external repository tasks
or independent holdout/generalization evidence. Prior frozen studies stay closed.
Known target only. No new language, Core, Skill or Host mutation capability.

## Conditions and predeclared order

- A: source acquisition plus current target body/declaration; no automatic direct
  semantic context. Has full source paging, literal search and complete generic
  symbol directory. This is not a full LSP/IDE comparison.
- B: ordinary ContextHost, same source/search/catalog/reference access.
- C: P42 BoundedTargetHost, same fallback and mutations.

Q01 billing normalization: A/B/C. Q02 nested shipping request: C/A/B.
Q03 retry-policy behavior propagation: B/C/A. No substitutions, repeats or tuning.
All use the same read_target view, body replacement, scope Guard, actual isolated
check/build/test, prepare/publish, fresh AIR verification and independent final
task/regression evaluation. Only information acquisition changes. No arm labels
enter initial model input; first request bytes are identical within each task.

The fixtures represent small application maintenance situations, not production
deployment. Inputs and tests were authored before model use. Q02 originally had
an invalid nominal alias/i64 assumption; zero-provider qualification detected it
and it was corrected to nested records before freeze. No model outcomes selected
tasks or definitions. Engineering candidates exist only in the qualification
script; no benchmark source, test assertions or past trajectory is model-readable.

## Model and resources

Official DeepSeek `deepseek-flash`, thinking enabled, reasoning effort low, via
the existing official API transport. Configuration checked against
[official thinking/tool continuation documentation](https://api-docs.deepseek.com/guides/thinking_mode/).
An unrelated two-request toy echo canary passed before freeze (748 reported
tokens), including tool arguments and continuation. Reasoning_content is retained
privately and sent back unchanged; never printed/published. Credentials are only
read by the Windows controller and sent to the official provider, not the model,
Linux fixture processes, public Git or evidence archive.

Per slot: at most12 requests,36 dispatched tools,480 active seconds,120000
cumulative reported-token **observation threshold**,4096 output cap,131072 exact
serialized request bytes,90-second HTTP deadline, concurrency1. No counting API,
retry, replacement, reset or operator repair. There is no provider hard aggregate
token cap; a request may overshoot the observation threshold. Cached input stays
in total; missing categories stay null. Complete returned actions drain after
usage recording even at the token threshold, subject to tool/wall/safety gates.
Incomplete responses never dispatch; duplicate IDs stop; successful publish
stops the tail; conflicts stop old-state tails. Provider outcome uncertainty or
common service/isolation/identity failure HOLDs the remaining schedule. Ordinary
candidate failure continues to the next predeclared slot.

Trusted Host inspections/draft parsing run in the existing trusted controller
boundary. All candidate builds and behavioral execution use the unchanged Linux
OS-isolated evaluator. This is not a sandbox claim for the whole trusted Host.

## Freeze and measurement

FREEZE.json contains actual tasks/source bytes, independent assertions (never
delivered), policies, shared documents/tool schemas, exact initial messages and
first-request hashes, runtime source hashes, SDK hashes, controller identity,
qualified engineering outcomes, schedule, model and resources. Commit/push before
scientific generation. Runtime must match; no placeholder input is frozen.
Machine paths/raw evidence remain local. Windows controls the actual WSL stdio
service, reusing existing Session and unchanged API/budget request helper.

Every actual source read/search delivery is metered against exact frozen UTF-8
source bytes and version; overlap/duplicates are counted. Empty EOF delivers zero
bytes. Target body representations and C projection bytes are separate metrics,
not silently called raw source. All tools/responses remain in private records.
Provider totals are the full-session economy endpoint, including repeated
context, references, reasoning and schema. Backend Native/evaluation work is
reported separately. No archived-response reconstruction or cross-slot transfer.

Predeclared favorable **developmental** screen: C correctness not lower than A,
median paired total-token C/A<=0.75, worst C/A<=1.5 and aggregate raw source
delivery lower. Report every task/arm, failure and censoring; no survivor-only
selection. Zero baseline raw source exposure cannot support a reduction claim.
If these tiny cases do not require much source, report that limitation, do not
inflate them or add cases until C wins. B/C distinguishes incremental automatic
projection only under this specific Host; A/C is not broad tooling superiority.

Results are not significance, causality, arbitrary-code comprehension or agent
correctness proof. No default promotion, new study or publication follows
automatically. Finish all scheduled slots or record a real common HOLD, then STOP.
