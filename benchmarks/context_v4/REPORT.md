# Compact context V4: do not promote as the default

8 November 2026. **All twelve fresh model slots succeed, but this configuration
does not establish a cost advantage over the matched text-proposal control.**
It passes the registered median screen against full-upfront context, with a
large adverse case. Keep the existing stable Host route as default; compact
context remains opt-in while dependency retrieval is improved.

## Delivered engineering

- A dedicated compact Host Skill and sectioned generic language reference.
- An opt-in five-tool entry: existing read/prepare/publish plus bounded public
  reference/source readers. Full docs remain available; source line endings
  remain exact, with explicit continuations and import/proposal authority.
- A common Result code-generation fix: direct Result parameters, lexical let
  bindings (including shadowing) and match tails no longer get an extra Ok.
  Executable source and authoritative AIR regression tests pass.

The existing three-tool server and 20/9-tool Native profiles are unchanged.
Mutation, actual P34 authorization, isolated candidate tests and fresh Native
publication verification still use the existing Host. This is not a new scope
exception or a weaker evaluator.

## Why the default remains unchanged

[Diagnostics](DIAGNOSTICS.json) show H01-T and H01-V4 each make five source
reads, including one rejected 260-line request against the 120-line bound.
V4 uses eight HTTP requests for H01; the upfront baseline uses three.
On-demand retrieval reduced initial context but increased repeated history
and round trips. This is observed query fanout, not a model correctness failure.
H04-V4 also uses an extra reference request relative to T. No arm needed a
second preparation, so candidate-repair savings do not explain this cohort.

The next concrete engineering hypothesis is dependency-complete bounded
context: include required nested type/enum declarations and targeted callee
information rather than making the model scan a module. Another candidate is
target-bound body-span patches, avoiding complete-body retranscription for
small edits while retaining occurrence-copy publication and the same Guard.
Neither has been demonstrated by this run. Test these as separate changes
with declared budgets and tail-regression criteria, rather than retuning this
consumed cohort until it clears a threshold.
