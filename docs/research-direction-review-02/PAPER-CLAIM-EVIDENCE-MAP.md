## Four distinct layers in manuscript language

1. **Implemented/expressible:** source/API and deterministic witness.
2. **Agent discovered/called:** actual model-tool and backend records.
3. **Connected/published:** actual target identity diff, Host authorization,
   underlying commit and fresh authority.
4. **Independently behaviorally evaluated:** executed tests and supported tested
   state relation; finite results, not a universal theorem.

Keep these separate from each other and from approval permissions, scope
authorization, stale rejection, mutation-locality and final task semantics.
The main contribution hierarchy is system → bounded case study → limitations
and negative results. Direction D must not become the paper's asserted novelty.

## Excluded claims/data

No E5/SS private statistics or transcripts, new significance tests, benchmark
prevalence estimates, causal stage-mediation effects, generalized language
comparisons, new tasks, replacement runs or reference-patch agreement metric.
An archive hash and an independently authored oracle are different assurances;
neither is an independent-human-label claim. Original frozen grades are never
overwritten by this handoff.
