## 2. Motivation

A Coding Agent can discover a semantic operation, create nodes, change a
target, pass transaction checks, and still fail to publish an authorized and
behaviorally correct maintenance result. ALVA makes those boundaries inspectable
in a controlled source/AIR system. The value of this paper is the concrete
system and a reproducible failure/control/composition story, **not** a claim that
all ordinary languages or tests are inadequate.

## 3. Contribution hierarchy
