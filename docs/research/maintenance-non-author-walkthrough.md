# Non-author maintenance walkthrough: handoff packet

**Status: NOT_EXECUTED / PARTICIPANT_UNAVAILABLE.** This file is a future
participant guide, not a filled result, recruitment message or user study claim.
Do not substitute the author, Codex, a synthetic response or CI for a participant.
No personal/company data, paid model account or credentials are needed.

## Session

Use a consenting developer who has not implemented ALVA. Provide the exact
reviewed commit and [public Quickstart](../maintenance-consumer-quickstart.md).
Use a disposable Linux/WSL environment, no production repository or private
inputs. No model generation is needed. Permit normal documentation lookup;
record any author assistance rather than silently fixing their environment.
Do not ask the person to approve architecture or compare success rates.

Ask the person to:

1. Identify prerequisites and launch the documented public example.
2. Find the malformed and behavior-failing results; explain whether either
   candidate was published and whether a rejected candidate can be repaired.
3. Identify the successfully published revision and what evidence tested it.
4. Locate the original source, authoritative AIR and final source-only handoff.
   Explain which project they would give to a colleague and why.
5. Follow the reproduction commands in a new output directory, without
   overwriting a previous result or editing the example in place.

The script supplies illustrative edits; completing it measures documentation
and handoff comprehension, not the participant's coding skill or Agent ability.
If they cannot install the supported environment, retain that setup failure.

## Minimal record (leave blank until an actual session)

- Date, exact checkout, OS/tool versions; omit identifying information.
- Setup elapsed time and failed commands/errors.
- Assistance requested/given and where the documentation was unclear.
- Participant's own explanation of published versus source state.
- Wrong assumptions about check PASS, scope, behavior or final handoff.
- Could the source-only handoff be located and independently reproduced?
- Recovery steps, unresolved obstacles and voluntary feedback.

Keep raw session notes private by default. Publish only a consented, redacted
summary. Do not invent timestamps, quotations, completed forms or participants.
Any usability repair must follow an observed obstacle; no automatic Core redesign,
benchmark, promotion or model run follows from this packet.
