# Proposed minimum measurement study — DESIGN ONLY

**Status: NOT_AUTHORIZED / NOT_STARTED.** No new task population, synthetic
case, candidate edit, model session, runtime mechanism or output label was
created/executed by RDR-01. This specification does not supersede any freeze.

## Question and falsifiable hypothesis

**RQ:** Does target- and authority-bound trace evidence reveal unrealized coding
treatments that a correctly implemented call+state+test baseline cannot already
classify from the same available records?

**H-D:** At least one fixed evidence situation below has a verifiably different
mechanism-realization classification under ordinary process/state accounting
versus object-bound attribution, and the latter can substantiate its distinction
without a reference patch, hidden model reasoning or a new behavioral oracle.
This is a potential measurement-specific gap, **not an established novelty**.

**Competing explanation:** Properly implemented existing process metrics plus
target diff, immutable candidate identity and independent tests already supply
all distinctions. AIR adds convenience or naming only. Current prior art makes
this explanation quite plausible; it must be allowed to win.

The strong comparator receives the same evidence, not an intentionally
incomplete log. “Extra information fixed missing information” is not the result
we seek. Any benefit against a weak `ok` counter is illustrative only.

## Strongest baseline and proposed comparison

**Baseline E0:** Existing source/AST/Git and process-evaluation practice:
match requested/received/dispatched calls by ID; verify tool/argument/status;
use exact before/after candidate and target diff; check the actual published
identity; associate independent compiler/test results with the tested revision.
In AIR cases it may read the provided AIR snapshots as a state representation.
Do not deny it those snapshots merely to favor E1.

**Candidate E1:** Map the **same** records to explicit exposure → dispatch →
construction → target attachment → published identity → independently tested
identity. A detached node is not target attachment; a no-op commit can publish
without realizing a requested change; denied invocation is not a backend
semantic rejection. Add no tests, semantic facts or trusted assumptions.

**Minimum viable counterexample specification:** P26's HE23-B no-op publication
is the exact existing counterexample to *commit status implies treatment
realized*. The strong E0 can inspect target-state diff, so it may resolve it
already. That would falsify incremental measurement need, not invalidate the
original failure observation. The other three fixed units test whether the
same classification is simply restating ordinary trace/state accounting.

References to compare first are CodeStruct/ACI, Verified Tool Calls, AFT,
tau-bench and process evaluation (SOURCES P1/P2/P19/P20/P22/P23). A new acronym
and four labels are not an adequate contribution.

## Independent evaluation criterion

Before any future analysis is run, freeze input file/archive identities,
schema mapping, missingness rules and the definition of realization for each
unit. Keep existing outcome labels separate from analyzer inputs. A useful
observation is a **task-relevant connected mutation**, not arbitrary graph
node creation. Publication requires authoritative identity change/retention
appropriate to the task; correctness requires the original independent test
record and exact tested revision. In no-change-required tasks, no-op may be
correct; none may be mislabeled just because its diff is empty.

Use observable record checks, not an LLM judge. A read-only verifier should
return concrete call IDs, hashes and before/after object relationships for
every classification. A separate evaluator compares these with immutable
published facts, without changing those studies' grades. Do not claim these
facts are independent human ground truth. Missing approval/state/test evidence
remains UNKNOWN. If independent human annotation is desired later, identify
actual annotators and agreement rather than calling Codex an independent
reviewer.

## Required changes, conditions and artifacts

- Future implementation: at most one read-only adapter/analysis module and
  tests in a new directory, reusing existing parsers/manifests. No Core,
  harness transport, MCP, Skill or historical executor edits.
- Required model conditions/calls: **none / 0**. Input-token API: 0. No budget
  experiment, resource extension or historical model retry.
- Artifacts: fixed input manifest; per-unit E0/E1 classifications and evidence
  pointers; missing-data matrix; disagreement/adjudication record; bounded
  summary. Public hashes/derived records only; no private transcript copies.
- Archive reads require integrity verification; no candidate is compiled or
  executed to manufacture missing evidence. This is not a dynamic replay.
- Relative effort: low for public evidence, moderate if licensed/private
  archive access and schema reconciliation are needed. No duration or paid
  model-cost promise.

## Success, failure and decision update

**Supporting signal:** a grounded realization distinction remains after E0 has
all equivalent records, and cannot be obtained by the standard state-binding
mapping without an explicitly identified additional assumption. Report exactly
that assumption; added effort or structured reporting alone is engineering.
Even success does not establish Agent utility, prevalence or global novelty.

**Abandonment:** if E0/E1 agree on all evidence-supported classifications, stop
the new-mechanism hypothesis, accept ordinary trace/state accounting, and
write the bounded failure/systems case study if worthwhile. Do not add model
slots, a different baseline, more difficult tasks or repeated calibration.

**Inconclusive:** insufficient archives or unmatched semantics means no new
model study; publish the limited evidence-access result or defer. Do not treat
UNKNOWN as a win. A demonstrated distinct gap would justify only a separately
reviewed mainstream-language replication design, not automatic implementation.

This proposal has no authority to restart closed experiments. It changes the
research decision only if reviewed results meet the above distinction; parity
ends the route. Reviewer may instead prefer immediate synthesis without even
this archival comparison.
