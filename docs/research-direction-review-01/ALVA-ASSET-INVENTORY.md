# What is actually worth retaining?

Source baseline and evidence-access policy: [SOURCES](SOURCES.md). These are
implementation/evidence classifications, not grades or a pooled success rate.

- **IMPLEMENTED**: concrete code exists at the pinned base.
- **ENGINEERING_FEASIBLE**: a deterministic executable witness was reported.
- **EXPERIMENTALLY_OBSERVED**: an identified real-model run produced the observation.
- **HYPOTHESIZED**: a future discriminating result, not demonstrated utility.
- **UNSUPPORTED**: a stated surface/path cannot perform the operation as tested.
- **UNKNOWN**: evidence missing, scope not checked, or property not established.

More than one status may apply to different claims about the same asset.

## Four non-interchangeable layers

1. **Expressible:** P25/P35/P37 deterministic compositions work; says nothing
   about a model choosing them.
2. **Discovered/called:** P24 tool exposure repair and P26 discovery show this
   is measurable separately; missing tools are not model syntax failures.
3. **Connected state change:** P26 detached references/no-op commit differ from
   P30/P32/P36 target-body changes. An `ok` constructor is not target attachment.
4. **Correct published behavior:** P30's blocked commit cannot be promoted to
   success; P33 check/commit passes with regression failure; P32/P36 independently
   pass. Scope, transaction validity, publication and behavior remain separate.

No inventory entry proves `.alva` indispensable to the next paper. Retain it
because it is a functioning, inspectable controlled instrument, not because
replacement cost or sunk effort establishes research novelty.
