# RDR-01 decision — shrink the claim, retain the instrument

Date: 2026-11-02. Canonical base:
`60902939732f03f5653d6b2ce320ed7ca25b4c17`.

**Primary:** Direction D, a bounded **archived-evidence treatment-realization
measurement comparison**, initially with zero new model calls. Question: can
coding-mechanism realization be classified more faithfully using target/state
lineage than by a strong existing call+state+test evaluator?

**Secondary:** Direction B, synthesize the P33–P36 shared-identity maintenance
case study. This is a fallback publication/synthesis option, not a parallel
path-copy implementation or model study.

**New production mechanism readiness: NONE ESTABLISHED.** Selecting a cheap,
falsifiable measurement question is not asserting that a novel method is ready.
Direction D is explicitly conditional on surviving strong prior art and baseline
parity. [Comparison](RESEARCH-DIRECTION-COMPARISON.md) gives all four routes the
same decision standard; [next design](NEXT-EXPERIMENT-SPEC.md) supplies a binding
abandonment rule rather than an open-ended roadmap.

## Why this decision, rather than another AEC or interface experiment?

[P38](../../benchmarks/p38_authorized_effect_contract/NOVELTY-DECISION.md)
must remain **NO_OBSERVED_INCREMENTAL_VALUE**. A/D = 4/4, B = 3/4,
P34 C = 2/4 against the stronger registered policy. Ordinary available tests
already detect the protected regression; an evidence-strength rule can also be
enforced by the source baseline. A/D share a combiner. D was a simulation,
not a production gate. P38 excludes a new decision-advantage claim **on those
cases with that equal evidence**. It does not prove all effect policies useless,
or that source/AIR have identical costs, concurrency or verification reuse.
None of those untested possibilities is currently a reason to build a system.

The public trajectory sequence supplies a better bounded problem:
unexposed operation (P24), discovery without attachment (P26/P28), connected
staging without host-authorized publication (P30), independently correct
publication (P32/P36), check-valid but behavioral regression (P33), and actual
scope denial (P34). These are different evidence states, not equivalent failures
and not a clean series of causal interventions. The possible contribution is
showing what inference is justified from such observations, not inventing tests
or making all runs PASS.

## Mainstream language decision: C

**ALVA controlled-mechanism research + mainstream-language external validation.**
This is a conditional two-platform research strategy, not permission to start
two implementation projects today.

| Consideration | Decision |
| --- | --- |
| Internal validity | Retain existing AIR/MCP/observer to inspect actual staged and published identities. Freeze toolchain/language; do not add a feature to manufacture an experimental gap. |
| External validity | If D survives its first strong-baseline comparison, prefer an independent Python source/AST+Git case to test whether the inference transfers. Do not infer language effects from different tasks or retrospectively pool runs. |
| Cost | Reuse standard Python/Git/CI and existing ALVA evidence; no Python AIR, second compiler, multi-language effect engine or bulk paid rerun. If the first comparison is parity, do not build the external experiment. |
| License risk | Use independent implementations/official tools with checked licenses. CodeStruct's pinned source carries CC-BY-NC-4.0, not ALVA Apache-2.0; read-only comparison is not clearance to copy it into the public product. |

ALVA's language is **not currently demonstrated scientifically indispensable**.
It remains useful for reproducing existing controlled phenomena and as an
instrument with observable authority. Immediate full migration would discard
that evidence continuity; exclusive ALVA research would perpetuate external
validity limits. Preserve the stable implementation, not a language-competition
promise.

## Explicit freeze / stop list

- Freeze grammar, types/effect extensions, new backend targets and new AEP/MCP
  primitives as research investments. Ordinary separately authorized maintenance
  of reproducible infrastructure is not prohibited.
- Do not build generic occurrence/path-copy, semantic navigation, obligation
  kernel/ledger, RecoveryContext expansion, batch patch or compaction to rescue
  these studies. P35/P36 already solve original MM02 with current operations.
- Keep compiler/native build, exact-byte transport, Linux OS isolation, stdio
  MCP, P31 scoped approval and P34 bounded Guard as stable infrastructure.
- Keep AEC v0 as an experimental reference and negative result, not a default
  production gate or a new effect-checking language.
- Stop static-projection/discovery tuning and from-zero HumanEval generation as
  the next primary research program. No difficulty calibration or enlarged pool.
- Pause A's new effectiveness runs; freeze C's generic version-binding novelty
  hypothesis; do not run P37 formal slots or restart E5/SS/REC/CLOSE/EFF/ECO.
- Preserve every frozen input, witness, failure, incident, archive identity and
  conclusion. No merge/delete/history rewrite is needed for repositioning.

## The nine final questions, answered

1. **Is the language irreplaceable?** No such necessity has been established.
   AIR is a useful fixed-case instrument; transferable measurement does not
   require `.alva`.
2. **What does CodeStruct cover?** Named AST reading/editing and structured
   action-space agent evaluation, including mainstream-repository evidence.
   ALVA cannot claim those broad ideas as new. Its different authority model
   remains a difference, not an observed general advantage.
3. **What did P38 rule out?** Incremental decision value over its strong
   equal-evidence source baseline in four synthetic cases; not every conceivable
   effect or concurrency hypothesis.
4. **Best remaining question?** Treatment realization and stage-specific
   attribution against a strong state-aware evaluator; D, with novelty uncertain.
5. **What stops?** Feature/platform expansion and another broad AEC or
   function-generation utility study; exact list above.
6. **Dual platform?** Yes, strategy C, with external validation conditional on
   an actual unmet measurement need. No immediate adapter work.
7. **Minimum next step?** Four fixed existing evidence situations, no candidate
   execution/new models; classify realization separately from final correctness.
8. **When to abandon?** If call+target-diff+test/authority baseline makes all
   grounded distinctions, stop the claimed new measurement mechanism. Do not
   make the baseline weaker or add cases until a favorable difference appears.
9. **What can be published now?** A bounded system/artifact description and
   transparent case/negative-result synthesis. Broad efficacy, language novelty
   and a mature methodology claim still lack evidence; see
   [publication assessment](PUBLICATION-ROADMAP.md).
